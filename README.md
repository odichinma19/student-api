# Student Management API (Flask)

A simple RESTful API built with Python and Flask to manage student records.  
This project demonstrates backend development, routing, JSON handling, and CRUD operations.

## 🚀 Features
- Get all students
- Get a student by ID
- Add a new student
- Update student information
- Delete a student
- JSON request/response handling

## 🛠 Technologies Used
- Python 3
- Flask
